# عربيتها واحنا نغطيها — car cover storefront

Static HTML, CSS, and vanilla JavaScript storefront. The site uses the supplied logo and car cover images, with an Arabic-first design, product browsing, Cover Lab prototype, and a cart stored in the visitor's browser.

## GitHub Pages

The site is ready to serve directly from the repository root. All asset paths are relative, so it also works at a project URL such as `https://USERNAME.github.io/arabeyetha-car-covers/`.

GitHub Pages should publish the `main` branch from the root directory. The `.nojekyll` file keeps static files as supplied. Changes pushed to `main` will appear after GitHub finishes deployment.

## Local preview

Open `index.html` with a local static server, for example:

```sh
npx serve .
```

## Business details to confirm

The product names, prices, fabrics, fit, shipping, payment, and return details are examples. The checkout prepares an inquiry only; it does not process payments or place an order. Add the brand's real WhatsApp number and email to `app.js` before enabling direct contact. Do not publish invented reviews.
